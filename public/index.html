Reproducibility

Training and serving

Training produces the classifier, vectorizer and metadata. The API loads these saved artifacts and applies the shared preprocessing function before every prediction.

  • Binary labels only; no fabricated neutral class.
  • Low-confidence predictions are flagged below 60%.
  • No BERT, transformers, paid APIs or external inference services.
  • The Streamlit version remains available for local demonstrations.
